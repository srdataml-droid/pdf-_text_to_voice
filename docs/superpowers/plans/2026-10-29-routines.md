# Recurring Routines Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox syntax for tracking.

**Goal:** Save bounded recurring routines into the timeline and show green/red/neutral progress per task.
**Architecture:** Pure RoutinePlanner and DailyProgress rules; SQLite v4 stores rules and task links; a focused RoutinesUi handles preview/save/stop using existing native reminders.
**Tech Stack:** Existing Java Android framework, SQLiteOpenHelper, AlarmManager, WorkManager.
**Spec:** docs/superpowers/specs/2026-10-29-routines-design.md

## Global Constraints
- Fully offline; no new permissions/dependencies.
- 1–90 calendar days, explicit selected weekdays, actual tasks and protected existing placements.
- Atomic persistence, reject stale previews, do not seed private tasks.

## Review Focus
- Overnight commitments and all-day events block placement.
- No room must be visible with no fabricated alarm.
- Two previews cannot overbook the same calendar revision.
- Stopping must preserve later individual edits/completion.
- Future tasks and empty days must not turn red or green.

# Reader source status — 13 November 2026

Complete current TypeScript/Vite Reader source, Android shell, folders, Manhwa collection, learning notes/highlights and narration-follow edits are included. Android manifest build settings target version 1.8 (code 13). TypeScript validation passes.

No private library, reading progress, notes, personal schedule, models, signing keys or APKs are included. Generated PDF assets and model packs are intentionally ignored. The current build script requires model packs: run the documented preparation step locally. A hosted web build needs an explicit user-controlled model provisioning strategy; an unprepared Vercel build will not work by simply importing this repository.

Known remaining work: folder/note data is separate from the full library backup; repeated quotes may highlight the first match; image-only Manhwa needs OCR for textual highlights; CBZ/CBR import is not implemented. Reader-to-Anchor activity sharing remains unimplemented. Browser functionality of the new organizer has not been fully tested. The earlier 1.8 APK was installed and launched on the phone; the source snapshot is not a claim of full feature validation.
